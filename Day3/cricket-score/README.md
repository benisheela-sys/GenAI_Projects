Live Cricket Score Bot
A Python automation project that uses Playwright to fetch live cricket scores from Cricbuzz, capture a screenshot of the match page, and save the score details into a text file.

Features
Launches Chromium browser using Playwright
Opens a Cricbuzz live score page
Waits for the score section to load
Extracts live match score information
Captures a full-page screenshot
Saves the score into a text file with timestamp
Includes exception handling for timeouts and errors
